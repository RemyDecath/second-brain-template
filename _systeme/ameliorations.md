# Améliorations

Remplace le cycle de vie des issues GitHub : toute proposition d'évolution du système passe par
cette file avant d'atteindre le socle (R8).

## Règle

Même question posée 2 fois, ou même correction faite 2 fois → l'agent **propose** une ligne ici,
sans jamais l'ajouter seul au socle. Une règle réutilisable ou une skill ne s'écrit qu'après la
**3e répétition réelle**, jamais par anticipation. Vidée à la rétro mensuelle
(`_systeme/routines.md`).
