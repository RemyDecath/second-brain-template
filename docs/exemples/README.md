# Exemples

Un projet et une casquette entièrement remplis, avec leurs faits datés, leurs liens et leur
registry de notes atomiques. Ils servent à **voir** ce que le pattern décrit en mots dans
`3_Ressources/Pattern_Extensibilite/Pattern_Extensibilite.md`.

Ils vivent dans `docs/`, donc hors du contexte de Copilot App : ils ne pèsent sur aucune
conversation et vous n'avez rien à supprimer avant de commencer. Les données sont fictives
(association « Les Amis du Parc »).

| Exemple | Ce qu'il montre |
|---|---|
| `EXEMPLE_Projet/` | Une note de contexte de projet : état, faits sourcés, points d'attention, liens. |
| `EXEMPLE_Casquette/` | Une casquette et sa note atomique extraite, avec le registry qui les relie. |
